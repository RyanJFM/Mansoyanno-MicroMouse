# Mansoyanno V3 🐭

### Autonomous Micromouse Robot

Mansoyanno V3 is the next iteration of our autonomous Micromouse robot, developed with the goal of building a faster, more reliable, and more capable maze-solving robot.

The project focuses on designing and developing a complete embedded robotic system, combining custom electronics, PCB design, motor control, sensor integration, and autonomous navigation algorithms.

Rather than simply assembling existing modules, the objective is to understand and engineer each subsystem from the ground up, creating a compact and optimized platform capable of navigating and solving mazes autonomously.

## 🎯 Project Objectives

- **Custom Electronics:** Design a compact custom PCB integrating the robot's essential electronic subsystems.
- **Power Management:** Develop reliable power regulation and distribution for the MCU, sensors, motors, and other peripherals.
- **Motor Control:** Improve motor driving, encoder feedback, and motion control for precise navigation.
- **Sensor Integration:** Develop reliable sensing systems for wall detection, orientation, and movement estimation.
- **Navigation Algorithms:** Implement maze exploration, mapping, pathfinding, and optimized navigation.
- **Performance Optimization:** Improve speed, accuracy, stability, and overall system reliability.

## ⚙️ System Development

The project is divided into several major engineering areas:

| Subsystem | Description |
|---|---|
| Power Management | Voltage regulation, power distribution, and battery monitoring. |
| Motor Control | Motor drivers, encoder feedback, and speed control. |
| Sensing | IR-based wall detection and inertial measurement. |
| Embedded System | Microcontroller, peripheral interfaces, and firmware. |
| Navigation | Maze mapping, flood-fill algorithms, and path planning. |
| PCB Design | Custom schematic design, PCB layout, and hardware integration. |

## 📚 Documentation

This repository also serves as an engineering notebook documenting the design and development process.

Each subsystem is studied and documented individually, covering:

- Circuit architecture and component selection.
- How individual ICs and electronic components operate.
- Design calculations and engineering considerations.
- PCB layout and implementation decisions.
- Testing, debugging, and future improvements.

The documentation aims to explain not only **what was implemented, but why it was implemented that way.**

## 🛠️ Development Approach

The development process follows an iterative engineering approach:

1. Research and understand the subsystem.
2. Study relevant datasheets and reference designs.
3. Design the schematic and select components.
4. Develop the PCB layout.
5. Manufacture and assemble the hardware.
6. Develop firmware and integrate the subsystem.
7. Test, evaluate, and optimize.

## 🚀 Project Status

Mansoyanno V3 is currently under development.

The focus is on understanding and designing the hardware architecture, beginning with power management and progressing through the remaining electronic and software subsystems.
